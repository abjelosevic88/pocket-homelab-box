Connect Cloudflare

You need a domain whose DNS is on Cloudflare (the free plan is enough). The box adds two records, name.yourdomain and *.name.yourdomain, pointing at your home, and gets its certificate itself.

Cloudflare asks you to allow “Pocket Box” to read your domains and edit their DNS.

Set up this device

Two quick steps on each device

Do this once on every phone and computer you use with the box.

This network can't reach the box's own address (); some routers block names that point into the home network. Until the router allows it, use the steps below.

1

Trust the box's certificate

The box encrypts everything with its own certificate. Install it once so your browser trusts it.

Download certificate

If the browser says “Insecure download blocked”, choose Keep: this page can't use https until the certificate is installed.

  1. iPhone or iPad: open the download, then Settings → Profile Downloaded → Install.
  2. Settings → General → About → Certificate Trust Settings → turn on “Pocket Box”.
  1. Open the file; Keychain Access adds it to the login keychain.
  2. Double-click “Pocket Box” → Trust → When using this certificate: Always Trust.
  1. Settings → Security → More security settings → Install from storage → CA certificate.
  2. Pick the downloaded file.
  1. Open the file → Install Certificate → Local Machine.
  2. Place it in “Trusted Root Certification Authorities”.
  1. Chrome: Settings → Privacy and security → Security → Manage certificates → Authorities → Import.
  2. Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, tick “Trust this CA to identify websites”.
